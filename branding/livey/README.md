# Livey Official Branding

This folder contains the official Livey branding assets.

## Official Colors

- Livey Orange: `#FF5B32`
- Livey White: `#FFFFFF`

## Official Logo

The Livey logo is the finalized Version 1 V-pin geometry.

It consists of:
- a thick rounded diagonal stroke,
- a rounded tapered location-pin-inspired shape,
- a distinctive negative-space gap between both shapes.

The logo geometry must not be modified.

## Official Wordmark

The horizontal Livey wordmark combines:
- the official V-pin symbol,
- the LIVEY lettering converted to vector paths.

Approved variations:
- fully orange,
- fully white.

Mixed-color wordmarks are not part of the official identity.

## Asset Structure

- `logo/` — standalone V-pin logo assets
- `wordmark/` — horizontal V-pin + LIVEY wordmark assets
- `app-icon/` — official mobile app icon
- `favicon/` — official website favicon assets

## Usage

Use SVG files for website branding whenever possible.

Use the orange variation on light backgrounds.

Use the white variation on dark backgrounds.

Do not:
- redraw the logo,
- alter its geometry,
- recolor it to unofficial colors,
- stretch or distort it,
- modify the spacing between the two V-pin shapes.

Runtime website copies may be placed under each website's public asset structure, but this folder remains the canonical source of truth.
